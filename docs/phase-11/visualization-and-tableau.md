# Phase 11 — Visualization and Tableau

## Objective

Deliver the **Share** stage of the project methodology: static and
interactive visualizations, an R / R Markdown analysis, a Tableau Public
dashboard, and data-storytelling outputs that communicate the fraud
findings to non-technical stakeholders.

- **Tableau dashboard** — an interactive Tableau Public dashboard
