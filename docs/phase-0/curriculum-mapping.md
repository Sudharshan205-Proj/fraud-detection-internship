# Internship Course Curriculum Mapping

## Purpose

This document maps the concepts, tools, technologies, and techniques taught during the internship course to their implementation within the Fraud Detection System project.

The purpose is to ensure that the final project demonstrates the course material rather than only the minimum requirements of the fraud detection project.

## Audit Rule

A course topic will only be marked as implemented after there is identifiable evidence showing where and how the topic is used in the project.

The project will not claim coverage of a topic merely because the topic is mentioned in documentation.
