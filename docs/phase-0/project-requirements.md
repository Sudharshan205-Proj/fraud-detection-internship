# Fraud Detection System — Project Requirements

## 1. Project Objective

Develop an internship-level Fraud Detection System capable of identifying potentially fraudulent financial transactions.

## 2. Mandatory Fraud Detection Requirements

The project must include:

- Fraud detection using financial transaction data
- A classification approach
- Anomaly detection
- Isolation Forest
- Autoencoder
- Class imbalance analysis
- SMOTE
- F1-score
- ROC-AUC
- Confusion matrix
- Model comparison

## 3. Internship Curriculum Requirements

The project must also demonstrate relevant concepts from all eight supplied internship course videos, including:

- Data analytics foundations
- Analytical thinking
- Problem definition
- Data collection
- Data preparation
- Data cleaning
- SQL
- Spreadsheets
- Data analysis
- Data visualization
- Tableau
- R programming
- RStudio
- R Markdown
- Case-study methodology
- Data ethics
- Data privacy
- Data quality
- Data storytelling
- Presentation and communication

## 4. Scope

This is an internship project.

The system is not intended to be a production banking or financial-services fraud platform.

The implementation should be understandable, reproducible, documented, and sufficiently complete to demonstrate the internship curriculum and project requirements.
