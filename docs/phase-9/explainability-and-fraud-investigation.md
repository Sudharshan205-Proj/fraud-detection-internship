# Phase 9 — Explainability and Fraud Investigation

## Objective

Interpret the selected Random Forest model and provide transaction-level
investigation support that prioritizes potentially suspicious
transactions for analyst review.

## Status

**Complete** — feature-importance analysis, permutation-importance
support, and the transaction-investigation workflow are complete
(see `docs/machine-learning/model-explainability.md`). The committed
artifacts below were produced from verified full-dataset runs and are
regenerated locally when the scripts run against the full dataset.

## What Was Produced

- **Explainability module** — `src/machine_learning/explainability.py`:
  `get_feature_importance`, `calculate_permutation_importance`,
  `save_feature_importance`, `plot_feature_importance`.

- **Feature-importance artifacts** — generated by
  `scripts/model_explainability.py`:

  - `docs/machine-learning/explainability/random-forest-feature-importance.csv`
  - `docs/machine-learning/explainability/random-forest-feature-importance.png`

  Feature importance indicates model dependence, not causation.

- **Fraud-investigation workflow** — `src/analysis/fraud_investigation.py`:

  - `prepare_features` / `train_investigation_model` — reuse the selected
    Random Forest and the standardized feature pipeline
  - `create_investigation_report` / `save_investigation_report` — fraud
    probability per transaction, sorted for triage, with investigation
    priority levels (Low / Moderate / High / Critical)
  - Output: `docs/machine-learning/explainability/fraud-investigation-report.csv`

- **Identifier treatment** — the high-cardinality account identifiers are
  never treated as numerical predictors.

- **Tests** — `tests/test_explainability.py` and
  `tests/test_fraud_investigation.py`.

## How to Reproduce

```bash
python scripts/model_explainability.py [--max-rows N]
python -m src.analysis.fraud_investigation [--max-rows N]
```

## Responsible-Use Notes

Predictions and explanations are decision-support outputs: a high fraud
probability or importance ranking does not prove fraud. Real-world
investigation requires additional context outside the PaySim dataset.
